# NanoLab

Открытый проект AI-лаборатории для проектирования и вычислительной проверки наноструктур, нанокомпонентов и, в перспективе, наномашин.

Репозиторий инициализирован для сохранения целей, архитектуры, программы экспериментов и дорожной карты. Физические расчёты и реализация лаборатории ещё не выполнялись.
