## 1. Мотивация (пилотные числа)

- `reference_pairs` v1 (окно `(0.05, 0.55]`, без ориентации) на авторском frame 0 `0b` (8378 нуклеотидов) нашёл **26–29 пар** при ожидаемых ~4000 для оригами-дуплекса: определение v1 не видит практически всю пару-популяцию. Следствие: `pairs_fraction` v1 неинтерпретируем (1.0 → 0.12–0.24 за 24k шагов при 28 опорных парах).
- Измеренное распределение расстояния до ближайшего комплементарного (нековалентного) нуклеотида на frame 0: доминирующая популяция **1.0–1.3** oxDNA-единиц (мода 1.2; 7746 нуклеотидов в бакетах 1.0–1.3), с антипараллельными a1-осями (мода a1·a1 = −1.0) — геометрия Уотсон–Крика в oxDNA. Популяция в окне v1 (0.5–0.7, ~250 нуклеотидов) имеет a1·a1 ≈ +0.8…+0.9 (параллельные оси) и парой НЕ является.
- Числа детекции v2 на frame 0 (факты, не подгонка): **mutual-nearest + greedy: 3300 пар**; greedy без mutual-nearest: **3975 пар** (95% нуклеотидов). Полная калибровка: `docs/work/executions/EX-NL3-002-PROTO-R1/evidence/v2-frame0.json`.

## 2. Определение v2 (замораживаемое кандидат-определение)

### 2.1 Кандидаты пары (i, j), i < j
1. базы комплементарны (A↔T, C↔G); j ≠ n3(i)/n5(i) (ковалентные соседи исключены);
2. минимально-имиджевое расстояние центров `d ∈ (0.05, 1.3]` (константы `PAIR_D_MIN_V2 = 0.05`, `PAIR_D_MAX_V2 = 1.3`);
3. **ориентационный критерий**: оси a1 антипараллельны, `a1_i · a1_j ≤ −0.3` (`PAIR_A1_DOT_MAX_V2 = −0.3`).

### 2.2 Mutual-nearest + матчинг (режим observables по умолчанию)
Каждый нуклеотид сохраняет только ближайшего квалифицированного комплемента; пара выживает, если выбор взаимен; затем — детерминированный жадный матчинг по `(d, i, j)` (как в v1: один нуклеотид — максимум одна пара). Результат — список `(i, j, d_ref)`, замораживается на референсном кадре (по умолчанию кадр 0) для всей траектории.

Обоснование выбора констант: окно и порог антипараллельности покрывают измеренную пару-популяцию frame 0; чувствительность счётчика к порогам мала (a1·a1 ≤ −0.3 / −0.5: 3975 ↔ 4012 пар при greedy; d_max 1.3 — граница, за которой популяция обрывается: бакет 1.3 = 148 против 1.2 = 4117). Вариант greedy без mutual-nearest (3975 пар) реализован параметром `mutual_nearest=False` и используется внутри деривации манифеста рук (полнота пар-графа важнее пер-парной уникальности); выбор основного режима для observables (3300, mutual) — **открытый пункт для Director-freeze**.

### 2.3 Компоненты на кадре t
- `pairs_fraction_v2(t)` = доля v2-референсных пар с `d(t) ≤ 1.3`. `|ref_pairs_v2| = 0` → null + статус `NO_REFERENCE_PAIRS` (наследует конвенцию v1).
- `long_bond_fraction(t)`, `displacement_max(t)`, `angle(t)` — **без изменений, v1** (R1 не пересматривается): ревизия R2 касается только детекции пар.

### 2.4 Пометки
Все парные метрики, вычисленные v2-детектором, помечаются `v2` (schema_version 2, `kind: e2_observables_v2_trace`, поле `pairs_v2`). v1-функции и константы R1 (`reference_pairs`, `pairs_fraction`, `PAIR_D_MIN/MAX = 0.05/0.55`) остаются без изменений как reference regression.
