- **Hinge angle**: конвенция R1 (PCA-оси, ориентация «на другую группу», acos, беззнаково). **Erratum к R1 §2.5 (pre-confirmatory, данные не затронуты): фактический диапазон — [0°, 180°]**, без свёртки θ↔180°−θ; любое будущее сравнение с углами статьи обязано учитывать дополнительный угол. ## 4. Гейты валидности кадра (заморожено; Director decision №2)

Кадр `STRUCTURALLY_INVALID(t)` при любом:
- `long_bond_fraction(t) > 0.1078` (= 2 × baseline 0.0539, пилотный frame 0; относительный критерий — абсорбирует свойство авторского init);
- `pairs_fraction_v2(t) < 0.50` (validity-гейт намеренно пермиссивен; качество оценивается распределением, не гейтом);
- `displacement_max(t) > 20.0`.

Угловая статистика — по валидным кадрам; все кадры репортятся. Невалидные ран-условия: digest mismatch, крэш движка, выход за бюджет (см. §5) — каждый фиксируется отдельно, FAILED/BLOCKED раны не переиспользуются.

## 5. Бюджет

≤ 3.5 ч wall на реплику (прогноз 2.9 ч), реплики параллельно; общий ≤ 4 ч + анализ ≤ 1 ч. Превышение → прерывание и фиксация (это валидный калибровочный исход, не провал протокола).

## 6. Статистика (заморожено)

Per-replica и пул: median, IQR, квантили 5/95; bootstrap CI (10,000 ресемплов, resampling seed 424242); energy drift; доля валидных кадров. No optional stopping; никаких остановок по результату угла. Исключения — только по гейтам §4.

## 7. Приёмка (после кампании, вне этого freeze)

Confirmatory-данные → END_ANALYSIS → REVIEWER (fresh) → Director: `E2-R1` outcome (measured distributions) и решение NL3-002 acceptance по критериям WORK_QUEUE («полная серия, распределения, статистика, все неудачи, карточка компонента»). Этот freeze не пред-суждает outcome.

## 8. Addendum (параметрическая серия NL3-002-PARAM; внесено 2026-09-12 ДО запуска 32b/53b/74b и до любых cross-variant сравнений)

Мотивация — измеренная стоимость (калибровка батча 11b: ~0.066 s/step на 8444 нт; 200000 шагов ≈ 3.7 ч > бюджета 3.5 ч; большие варианты медленнее), НЕ исходы. Решения:

1. **Параметрическая серия (11b/32b/53b/74b) исполняется при steps = 150000**; сравнение вариантов — по общему окну t ≤ 150000. Батч 11b (прерван по §5 на 12600 s ≈ 184000 шагов, 46 кадров) покрывает окно и ре-срезается до t ≤ 150000 без перезапуска.
2. Гейты §4, статистика §6, seeds-тройка, digest-гейт и бюджет ≤ 3.5 ч/реплику — без изменений.
3. Confirmatory 0b остаётся 200000 (как заморожено); для кросс-вариантной таблицы 0b ре-срезается до того же окна t ≤ 150000 (вторичная таблица; первичный результат 0b не пересматривается).
4. Батчевый REVIEWER покрывает все параметрические execution'ы одной сессией (протокол идентичен, различия — только subject).
