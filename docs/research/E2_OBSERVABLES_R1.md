# E2 Observables R1 — замороженные определения наблюдаемых (pre-E2)

Статус: FROZEN (2026-09-12, EX-NL3-002A-R1). Определения фиксируются **до** любого запуска observables на production-данных кампании E2. Изменение любого пункта после просмотра production-данных — только новой ревизией `E2_OBSERVABLES_R2` через отдельный WO (hard rule: acceptance criteria / определения не меняются post hoc).

Класс источника: все определения ниже — **first-principles** (построены из общей геометрии oxDNA), а не извлечены из SI статьи Shi–Castro–Arya. Соответствие определений SI остаётся открытым вопросом **U-obs-1** (SI не pinned; получение SI — отдельное owner-решение). До закрытия U-obs-1 любые сравнения с числами статьи — некорректны по определению.

Реализация: `scripts/e2/observables.py` (stdlib-only, детерминированная арифметика в фиксированном порядке, канонический байт-детерминированный JSON-отчёт). Определение считается корректным, если реализация воспроизводит его на синтетических траекториях с аналитически известным ответом (тесты `tests/test_e2_pre_e2.py`).

## 1. Единицы и конвенции

1. Координаты — единицы длины oxDNA (oxDNA length unit ≈ 0.8518 nm; пересчёт в нм НЕ выполняется, значения публикуются в oxDNA-единицах).
2. Угол — **в градусах**; радианная версия вычисляется как `rad = deg × π / 180` и публикуется рядом.
3. Все расстояния — минимально-имиджевые по периодической коробке (minimum image convention) при прямоугольной коробке.
4. Отчёты не содержат wall-clock данных; детерминизм — два прогона на одном входе → байт-идентичные JSON.

## 2. Hinge angle `angle(t)` — определение v1

Вход: валидированные topology (.top), конфигурация/кадр траектории, **замороженный манифест групп** `{"arm_a": {"nucleotides": [...]}, "arm_b": {"nucleotides": [...]}}` (0-based индексы нуклеотидов топологии).

1. Для каждой группы `g` вычисляется центроид `c_g` и ковариационная матрица `C_g` позиций (без вычитания веса).
2. Главная ось группы — собственный вектор `C_g` с наибольшим собственным значением (аналитический симметричный 3×3 солвер, собственные значения сортируются по убыванию).
3. Вырожденность (критерий R1.1, скорректирован 2026-09-12 до любых данных): ось неопределена, если точечное множество не имеет доминирующего направления вытянутости — `λ1 < 1e-12` (нет протяжённости) либо `(λ1 − λ2) / λ1 < 1e-9` (изотропное облако: два старших собственных значения совпадают). Идеально прямая линия (`λ2 = 0`) имеет идеально определённую ось и НЕ считается вырожденной. В таких случаях кадр помечается `ILL_DEFINED_AXIS`, угол = null (не число-заглушка). *(Коррекция R1.1: в исходной редакции R1 ошибочно использовался порог `λ2/λ1 < 1e-9`, который помечал бы прямые оси как неопределённые; правка внесена до любого применения observables к данным, в том числе синтетическим прогонам валидации — поэтому ревизия остаётся R1.)*
4. Знаковая конвенция (разрешает двузначность собственного вектора): ось ориентируется так, чтобы `axis · (c_other − c_self) > 0` (ось «смотрит из группы на другую группу»). Если `|axis · (c_other − c_self)| < 1e-9`, ориентация помечается `AMBIGUOUS_ORIENTATION` (значение угла сохраняется, флаг публикуется).
5. `angle = acos(clamp(axis_a · axis_b, −1, 1))` в градусах, диапазон **[0°, 90°]**. Конвенция принципиально беззнаковая: θ и 180° − θ неразличимы; это зафиксированное ограничение v1, а не результат подгонки.
6. Требование к манифесту: каждая группа ≥ 3 нуклеотида, группы непусты и не пересекаются, все индексы в диапазоне топологии. Нарушение → ошибка (fail-closed).
7. **Открытый пункт U-obs-1:** выбор групп (какие нуклеотиды образуют «руки» шарнира 0b) не определён до pinned SI / авторского определения; манифест рук для 0b обязан быть пререгистрирован в `E2-PROTO-R1` до первого production-анализа. До этого observables на реальных данных источника не применяются (только синтетика).

## 3. Structural integrity — определение v1

Цель: отделить «угол раскрылся» от «конструкция развалилась». Три компоненты; пороги валидности кадра фиксируются в `E2-PROTO-R1` (здесь — только измеримые величины и пороговые константы алгоритмов, не acceptance-пороги).

### 3.1 Reference base pairs
1. Референсные пары строятся из референсного кадра (по умолчанию — кадр 0 траектории) следующим алгоритмом: кандидаты = упорядоченные пары `(i, j)`, `i < j`, базы комплементарны (A↔T, C↔G), `j ≠ n3(i)/n5(i)` (исключены ковалентные соседи), минимально-имиджевое расстояние `d ∈ (0.05, 0.55]`. Кандидаты сортируются по `(d, i, j)`; жадный матчинг: каждый нуклеотид входит максимум в одну пару. Результат — список `(i, j, d_ref)`, замораживается для всей траектории.
2. Константы алгоритма (v1, пересмотр — только в E2-PROTO): `d_min = 0.05`, `d_max = 0.55`.
3. Ограничение v1, зафиксированное честно: ориентационный критерий (антипараллельность нормалей баз) НЕ проверяется; ложные кандидаты подавляются только взаимной ближайшести и матчингом «один нуклеотид — одна пара».

### 3.2 Компоненты на кадре t
1. `pairs_fraction(t)` = доля референсных пар с `d(t) ≤ 0.55`. При `|ref_pairs| = 0` → `pairs_fraction = null` (кадр не может быть оценён по парам — помечается).
2. `long_bond_fraction(t)` = доля ковалентных связей (топология `n3`) с `d(t) > 1.0` (порог согласован с `long_bond_threshold` инструмента NL3-001 по смыслу «растянутая связь»).
3. `displacement_max(t)` = максимум по нуклеотидам минимально-имиджевого `|r(t) − r(ref)|`.
4. NaN/Inf в любом входе → ошибка парсера (fail-closed, наследует `ConfError`).

### 3.3 Критерий невалидного кадра (структурного)
Кадр `STRUCTURALLY_INVALID(t)`, если выполнен **любой** пункт: `long_bond_fraction(t) > θ_bonds`, `pairs_fraction(t) < θ_pairs`, `displacement_max(t) > θ_disp`. Значения `θ_bonds / θ_pairs / θ_disp` — acceptance-параметры и **сознательно не назначаются** в R1: они freeze'ятся в `E2-PROTO-R1` после пилота, до confirmatory-прогонов. Угол кадра со `STRUCTURALLY_INVALID = true` публикуется, но не участвует в распределении валидных углов (правило распределения фиксируется в E2-PROTO).

## 4. Валидация определения (обязательная)

1. Синтетические траектории с аналитически известным углом: 0°, 45°, 90° → восстановленный угол совпадает в пределах 1e-6 градусов.
2. Интактная структура → `pairs_fraction = 1.0`, `long_bond_fraction = 0.0`.
3. «Красивый угол развалившейся конструкции» (сдвиг одной руки на 50 единиц при неизменном угле осей) → угол сохраняется, integrity FAIL — демонстрация того, что integrity обязателен.
4. Тампер байта входа → digest FAIL; усечённая траектория → ошибка парсера; NaN → ошибка.

## 5. Границы применения R1

- На данных источника `DNA-hinge-simulations` observables применяются только после: (а) digest-gated digest-проверки входов (G1 = B), (б) пререгистрации манифеста рук 0b в E2-PROTO-R1.
- Настоящий R1 не создаёт научных утверждений о реальном шарнире (campaign NOT_EVALUATED, E2 = NOT_RUN, claim class инструмента — C0_SOFTWARE_ONLY).
