# Cu bulk / EMT R1 — источники и права

Пакет фиксирует один эталон для проверки изотермического объёмного модуля монокристалла FCC Cu вблизи 0 K. Статус: подготовка C0, физический расчёт не выполнен, P0 остаётся OPEN. Числа и привязки находятся в [реестре источников](sources.json), а пределы сравнения — в [черновике протокола](protocol.json).

## Экспериментальный эталон

W. C. Overton, Jr., и J. Gaffney, *Temperature Variation of the Elastic Constants of Cubic Elements. I. Copper*, *Physical Review* **98**, 969–977 (1955), [DOI 10.1103/PhysRev.98.969](https://doi.org/10.1103/PhysRev.98.969). Авторы измерили времена прохождения 10 МГц ультразвуковых импульсов в монокристаллах спектроскопически чистой Cu в диапазоне 4,2–300 K. Образцы и примеси описаны на с. 972–973. Адиабатические константы получены из акустических измерений и сглажены с нулевым наклоном при 0 K (с. 974). Уравнения (5)–(6), с. 974–975, задают термодинамическую поправку `K^T = K^S/(C_p/C_v)`.

| Что сверять | Локатор | Значение и условия |
| --- | --- | --- |
| Изотермический объёмный модуль `K^T` (`B_T` в протоколе) | с. 975, Table II, строка `T = 0 K`, столбец `K^T` | `14.203 × 10^11 dyn/cm² = 142.03 GPa`; экстраполяция, а не измерение при 0 K |
| Ближайшая экспериментальная опора | с. 976, Table III, строка `P, 4.2 K`, столбец объёмного модуля | `14.20 × 10^11 dyn/cm²`, **адиабатический** модуль; только пояснение происхождения эталона |
| Оценка погрешности в статье | с. 974, текст перед Eq. (5) | ±0,34 % — вероятная погрешность вычисленного **адиабатического** `K^S`. Авторы не дают отдельной неопределённости для значения `K^T` при 0 K. |

Пересчёт единиц: `1 dyn/cm² = 0.1 Pa`, следовательно, `10^11 dyn/cm² = 10 GPa`. Число знаков в Table II отражает округление опубликованного значения, а не абсолютную точность. В таблице нет отдельного численного значения внешнего давления; сравнение с расчётом при нулевом давлении использует приближение обычных лабораторных условий. Экстраполяция эксперимента к 0 K также не исключает вклад нулевых колебаний решётки. Оценка погрешности источника не является допуском протокола.

Условия использования: [страница APS](https://journals.aps.org/pr/abstract/10.1103/PhysRev.98.969) указывает © 1955 American Physical Society. Страницы и таблицы сверены двумя участниками по индексированному [PDF издателя](https://harvest.aps.org/v2/journals/articles/10.1103/PhysRev.98.969/fulltext), включая Table II, а не только аннотацию. Прямой GET к Harvest в текущем окружении вернул HTTP 401, PDF по журнальной ссылке — HTTP 403; для доступа к оригиналу может потребоваться подписка. В репозитории хранится только [краткая фактическая выписка NanoLab](source-artifacts/overton-gaffney-1955-facts.json) с хешем и размером. Хеш выписки не является хешем оригинального PDF: его байты не получены. Полный текст, таблицы и сканы не распространяются. Перед заморозкой протокола reviewer должен иметь возможность сверить указанную ячейку с оригиналом по DOI.

## Модель и воспроизводимые пины

Объект сравнения — ASE 3.26.0, `ase.calculators.emt.EMT(asap_cutoff=False)`, только Cu. В [исходнике тега ASE](https://gitlab.com/ase/ase/-/blob/3.26.0/ase/calculators/emt.py) закреплены элементные параметры и алгоритм cutoff. При `False` cutoff определяется по наибольшему атому всей таблицы параметров, поэтому результаты нельзя подменять результатами ASAP, OpenKIM или сборки с `True`. [Документация ASE](https://docs.ase-lib.org/ase/calculators/emt.html) приводит связь реализации с K. W. Jacobsen, P. Stoltze и J. K. Nørskov, *Surface Science* **366**, 394–402 (1996), [DOI 10.1016/0039-6028(96)00816-3](https://doi.org/10.1016/0039-6028(96)00816-3).

[PyPI release ASE 3.26.0](https://pypi.org/project/ase/3.26.0/) публикует wheel и sdist под `LGPL-2.1-or-later`. В `sources.json` закреплены URL, SHA-256 и размер обоих архивов, модуля EMT и лицензионных файлов. `member` указывает путь внутри архива, поэтому хеш и размер соответствуют извлечённым байтам этого файла. Байты wheel и sdist проверены по метаданным PyPI; `emt.py` из wheel совпал побайтно с модулем в sdist и с raw-файлом тега GitLab. SHA-256 модуля совпал с [историческим pilot manifest](../../../../examples/atomistic/runs/cu-emt-demo-r1-001/manifest.json); результат пилота не используется как физический эталон. Wheel `LICENSE` — уведомление ASE, а полный текст LGPL 2.1 находится в `COPYING.LESSER` в sdist. Архивы и код ASE не копируются в NanoLab, сохраняются ссылки и пины для отдельной загрузки. При будущем запуске нужен отдельный пин фактически установленного окружения.

### Что даёт сравнение

Источник модуля — эксперимент, не расчёт той же EMT. Однако [описание теории ASE](https://docs.ase-lib.org/ase/calculators/emt.html#energy) связывает параметры `E0`, `s0` и `lambda` с энергией когезии, равновесным объёмом FCC и кривизной `E(V)`, соответственно. Поэтому `B_T` чувствителен к параметризации. Не подтверждено, использовалось ли именно число Overton–Gaffney в калибровке; проверка классифицирована как согласованность в объёме, независимый holdout в R1 отсутствует. Параметр решётки и когезионная энергия также не добавлены как независимые проверки. Совпадение по `B_T` не переносится на сдвиговые константы, дефекты, поверхности, свободные наночастицы, динамику при конечной температуре или ресурс конструкции. Для таких выводов нужны отдельные эталоны и протоколы.
