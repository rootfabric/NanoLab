# Owner Decision Memo D2 — лицензия собственных материалов NanoLab

Статус: **memo для owner-решения** (программа D2). Решение агентом не принимается и не назначается — [LICENSE_POLICY](../../LICENSE_POLICY.md). Опции кода/документации уже зафиксированы в матрице NL0-002 (`docs/research/DEPENDENCY_LICENSE_MATRIX.md` §3); этот memo добавляет release-специфичные соображения NL5 и шаблон записи решения.

Срок: решение требуется **до публичной публикации** `nanolab-components-v0.1` (NL5-001-D). Сборка пакета от решения не зависит: `RIGHTS.json` поддерживает состояние `UNDECIDED_PENDING_OWNER_DECISION` (draft-only, публикация заблокирована линтером).

## 1. Что лицензируем

| Слой | Материал | Комментарий |
|---|---|---|
| Код | репозиторий NanoLab (harness, release tooling, analysis scripts) | без oxDNA и upstream-кода — они не вендорятся |
| Docs | README, control docs, протоколы, ROADMAP | — |
| Data | карточки компонент, измеренные распределения, манифесты | производные результаты, НЕ upstream-входы |
| Модели/веса | отсутствуют | n/a сейчас |

Upstream-контекст (закрыто G1-решением, не пересматривается этим memo): источники E2 — `REFERENCE_ONLY`, download-on-run по exact pinned commit, durable-cache запрещён, **производные результаты публикуются**. E1-фикстуры oxDNA — GPL-3.0, `DOWNLOAD_ON_SETUP`; в пакет они не входят.

## 2. Варианты: код

| Опция | Сильные стороны | Слабые стороны / риски |
|---|---|---|
| **MIT** | максимальная простота, нулевой барьер для внешнего воспроизведения (цель NL5-002) | нет явного patent grant; минимальная защита от патентных претензий |
| **Apache-2.0** | явный patent grant; защита контрибьюторов; стандарт для научной инфраструктуры | длиннее; чуть выше порог входа |
| GPL-3.0-or-later | гарантия открытости производных | отпугивает часть научных пользователей; избыточно для цели «внешнее воспроизведение» |
| BSD-3-Clause | как MIT + non-endorsement пункт | почти эквивалентен MIT; лишняя сущность |

Совместимость: ни одна опция не конфликтует с тем, что NanoLab **не распространяет** upstream-код (download-on-run); GPL-фикстуры E1 в пакет не входят, поэтому выбор MIT/Apache не создаёт GPL-обязательств для пакета.

## 3. Варианты: docs + data

| Опция | Сильные стороны | Слабые стороны / риски |
|---|---|---|
| **CC-BY-4.0** | атрибуция сохраняется; стандарт научных данных; совместима с данными-производными от рестриктивных источников (мы публикуем свои измерения) | требует атрибуции у потребителей |
| CC-BY-SA-4.0 | гарантия share-alike | virus-эффект осложняет интеграцию данных другими проектами |
| CC0-1.0 | нулевые барьеры | отказ от атрибуции; для научных данных часто нежелателен |

Примечание о научных данных: карточки содержат числа, извлечённые из опубликованного upstream evidence (REFERENCE_ONLY). Публикуем мы **свои** производные результаты — это разрешено G1-решением; сами upstream-файлы по-прежнему не распространяются независимо от выбора нашей лицензии.

## 4. Release-специфические точки применения решения

1. `RIGHTS.json`: поля `own_code_license` / `own_docs_data_license` (значение `UNDECIDED_PENDING_OWNER_DECISION` → публикация заблокирована).
2. `CITATION.cff`: поле `license`.
3. GitHub repo: файл `LICENSE` (сейчас намеренно отсутствует).
4. `docs/research/DEPENDENCY_LICENSE_MATRIX.md`: финальная колонка решений.

## 5. Шаблон записи решения (заполняет владелец)

```text

Date (UTC):            <...>
Code:                  <MIT | Apache-2.0 | GPL-3.0-or-later | BSD-3-Clause>
Docs+Data:             <CC-BY-4.0 | CC-BY-SA-4.0 | CC0-1.0>
Rationale:             <1-3 строки>
Recorded by:           <owner / agent under owner instruction>
Supersedes:            UNDECIDED_PENDING_OWNER_DECISION state in RIGHTS.json
Applies from:          <package version / repo commit>
```

Решение фиксируется отдельным control record в `docs/control/` (по образцу `E2_SOURCE_RIGHTS_G1_DECISION_R1.md`) и исполняется отдельным bounded WO.

## 6. Что memo НЕ делает

- не выбирает лицензию и не задаёт сроков решения;
- не является юридическим заключением (правило `LICENSE_POLICY.md`);
- не меняет права upstream-источников и G1-решение.
