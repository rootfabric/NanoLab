# Доказательства и отчёты приёмки

Сейчас отсутствуют результаты научных экспериментов. Отчёт проверки документации, если добавлен, не считается физическим evidence.

## Пакет научного результата

Идентификатор опыта/кампании; subject commit и tree; рабочее дерево; версия протокола; модель/движок и окружение; hashes исходных файлов; команды; ресурсы; seeds и начальные состояния; stdout/stderr; raw data manifest; анализ; наблюдения; uncertainty; критерии приёмки; фактический вывод; ограничения; reviewer и степень независимости.

Не публиковать секреты, личные абсолютные пути и данные без прав. Большие файлы хранятся внешне со стабильным манифестом. Отчёт должен позволять проверить происхождение любого числа.

## Типы отчётов

DOCUMENTATION_CHECK — ссылки, структура, согласованность плана. SOFTWARE_CHECK — тесты кода и обработки ошибок. PHYSICS_REPRODUCTION — воспроизведение эталона. SCIENTIFIC_CAMPAIGN — исследование вариантов и гипотезы. EXTERNAL_VALIDATION — внешнее вычислительное или физическое сопоставление с точным описанием независимости.

Эти типы не взаимозаменяемы. Отрицательное научное наблюдение может быть принято; сломанный parser не может служить доказательством отрицательной гипотезы.

## Закрытие стадии

Указать выполненные критерии, unresolved limitations и ссылки на реальные артефакты. `PASS` без данных и команды проверки не принимается. При смене кода/модели/протокола перечислить повторённые проверки. После исправления не переносить старый verdict автоматически.
