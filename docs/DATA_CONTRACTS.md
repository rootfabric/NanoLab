# Контракты данных и жизненный цикл

Статус: требования для будущей реализации. Это не объявление о наличии Python API или готовых JSON Schema. Схемы и валидаторы создаются в NL2-001.

## Объекты

| Объект | Обязательное содержание |
|---|---|
| ResearchGoal | Целевая функция, observables, ограничения, допустимое пространство, бюджет, критерий остановки |
| DesignArtifact | Идентификатор, версия, representation, состав/топология/геометрия, единицы, mapping, источник, права, checksum |
| ModelCard | Движок, модель, версия/commit, параметры, область применимости, известные ограничения, ссылки на проверки |
| Protocol | Версия, стадии подготовки и измерения, условия, численные настройки, seed-политика, наблюдения, критерии качества |
| ExperimentSpec | Goal + Design + Model + Protocol + ResourceBudget; замороженный идентификатор спецификации |
| RunRecord | Spec ID, attempt ID, исполнитель, среда, команды, время, exit code, ресурсы, stdout/stderr, checkpoints |
| Observation | Название, определение, единицы, оценка, физический разброс, статистическая ошибка, метод анализа, область данных |
| EvidenceRecord | Claim ID, тип утверждения, исходные артефакты, run IDs, анализ, проверки, ограничения |
| ComponentCard | Функция, интерфейсы, среда, нагрузка, рабочий диапазон, отказ, энергоснабжение, validation level |

Все машинные поля и enum — на английском. Путь файла не заменяет его идентичность: требуется checksum. Неизвестное значение явно отмечается UNKNOWN; отсутствие проверки не кодируется нулевой ошибкой или PASS.

## Представления

Для DNA_COARSE_GRAINED необходимы ориентации, топология цепей и mapping к исходному дизайну. Для ATOMISTIC — атомы, ячейка/границы и соответствующие модельные данные. COMPONENT_REDUCED содержит степени свободы и проверенную эффективную модель, а не атомистическую правдоподобность по умолчанию.

Единицы модели и физические единицы хранятся раздельно; преобразования имеют источник и версию. Нельзя автоматически переводить шаги oxDNA в экспериментальные скорости. Величины энергии от разных моделей нельзя сравнивать до согласования определения и отсчёта.

## Статусы запуска и научного результата независимы

Исполнение: PLANNED → VALIDATED → QUEUED → RUNNING → COMPLETED. Альтернативные конечные состояния: FAILED_EXECUTION, CANCELLED, BLOCKED_ENVIRONMENT. Повтор создаёт новый attempt ID и сохраняет предыдущую попытку.

Научный анализ: NOT_ANALYZED, INVALID_INPUT, INVALID_NUMERICS, INSUFFICIENT_SAMPLING, OUTSIDE_MODEL_SCOPE, VALID_WITH_LIMITATIONS.

Итог гипотезы: NOT_TESTED, SUPPORTED_WITHIN_MODEL, NOT_SUPPORTED_WITHIN_MODEL, INCONCLUSIVE, EXPERIMENTALLY_COMPARED. Последнее не означает автоматического согласия: направление и величина расхождения записываются отдельно.

COMPLETED не устанавливает VALID_WITH_LIMITATIONS. Сбой среды не устанавливает NOT_SUPPORTED_WITHIN_MODEL. Статус эксперимента в плане NOT_RUN отличается от статуса отдельной вычислительной попытки.

## Неизменяемость и ключи

Изменение конструкции, модели, протокола или метода анализа создаёт новый идентификатор/версию. Исходные данные не перезаписываются при переанализе. Ключ кеширования включает содержимое входов, модель/версию, настройки, seed и существенные параметры среды; имя файла недостаточно.

Resume допустим только с совместимым checkpoint и зарегистрированной историей. Потеря связи с исполнителем не означает, что job остановился: прежде чем повторять, нужно проверить его фактическое состояние. Гарантию exactly-once вычислений не обещать; цель — обнаружение дублей, идемпотентная регистрация и контролируемые попытки.

## Provenance и архив

Цепочка: source → imported design → transformations → specification → run → analysis → observation → claim. AiiDA сохраняет относящиеся к нему процессы; остальные сведения регистрируются явно. [S05–S06](research/SOURCES.md).

Большие файлы размещаются вне Git. Манифест включает URI, размер, checksum, формат, лицензию, доступ и retention. Отчёт с исчезнувшими исходными данными теряет заявленный уровень воспроизводимости. Журнал и манифест не должны содержать токены или пароли.

## Контракт знаний

Каждый фрагмент имеет source ID, точное место в источнике, тип REPORTED / CALCULATED / ASSUMED / UNKNOWN и дату либо версию получения. LLM-резюме не заменяет первичный источник. Данные статьи, вычисленные свойства и предположение агента нельзя объединять в одно безымянное поле.
