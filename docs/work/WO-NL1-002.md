## Цель

Первый end-to-end вертикальный путь E1 по пререгистрированному `E1-PROTO-R1` (acceptance каталога NL1: «one frozen non-AI reference path executes end-to-end with measured resources»):

1. **Preparation** (go/no-go §4, не наука): fixture из сырых blob'ов pinned commit (SHA-256 4/4 до запуска), пересборка engine по `ENGINE_ENVIRONMENT_R1` §3 на campaign-машине с записью SHA-256 бинарей, импорт-проверки.
2. **T1 production run** (`E1-R1-S001`): verbatim `quick_input` (байт-точно из raw blob, steps=1e6), seed — случайный (upstream-семантика), механический анализ §5.1 (среднее колонки 2 против оракула −1.37970256144 ± 0.15) + целостность §5.2.
3. **Pilot** (`E1-R1-P001..P003`): ровно 3 независимых прогона (та же конфигурация §3, случайные seed), помечены `PILOT`, в evidence кампании НЕ засчитываются (§6.4).
4. **Freeze `R_confirm`**: публикация `E1-PROTO-R2` (superseding только §6.4: R_confirm ≥ 2 с письменным обоснованием по разбросу пилота и стоимости) до confirmatory кампании NL2-002. Полоса §5.1 и критерии не меняются.
5. **Archive**: artifacts.manifest.json (SHA-256/size/producer) на все выходы; raw-выходы малы (сотни KB) — в Git целиком.
