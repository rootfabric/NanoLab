## Как брать задание

Статус READY означает готовность планирования, не разрешение на неограниченные расходы. Из одного Work ID при необходимости создаётся небольшой дочерний WO с точным scope; не дробить работу до бесконечного административного процесса. Все дочерние задания ссылаются на родителя.

Перед стартом проверить зависимости в actual state. После задания обновить журнал и evidence. Только после принятого результата изменить статус; commit без приёмки — IMPLEMENTED, не автоматически ACCEPTED.

## Правила параллельности

Параллельная подготовка `NL0-002` и `NL0-003` была разрешена и выполнена без file/scope конфликтов. Runtime, схемы и статусы имеют одного интегратора. Вспомогательная работа не открывает автоматически материалы, наноэлектронику или физический синтез.

## Политика неизвестных значений

Exact E1/E2 reference sources выбраны и закреплены; условия и численный критерий E1 пререгистрированы (`E1-PROTO-R1`); 298 K vs 300 K для E2 закрыт decision rule'ом (`E2-SETUP-R1` §5). По-прежнему не выбраны/не приняты: engine/build versions и measured compute budget (NL1-001 и первые прогоны), права redistribution для E2 data (owner), tolerances/пороги целостности E2 и целевой интервал угла (E2-PROTO после пилота). Эти значения принадлежат следующим bounded Work Orders и не должны подставляться произвольно.
