## Как брать задание

Статус READY означает готовность планирования, не разрешение на неограниченные расходы. Из одного Work ID при необходимости создаётся небольшой дочерний WO с точным scope; не дробить работу до бесконечного административного процесса. Все дочерние задания ссылаются на родителя.

Перед стартом проверить зависимости в actual state. После задания обновить журнал и evidence. Только после принятого результата изменить статус; commit без приёмки — IMPLEMENTED, не автоматически ACCEPTED.

## Правила параллельности

После принятия NL0-001 аудит прав (`NL0-002`) и научная постановка (`NL0-003`) разблокированы одновременно и могут готовиться параллельно, если не редактируют одну сущность и сохраняют независимый handoff. Runtime, схемы и статусы имеют одного интегратора. Вспомогательная работа не открывает автоматически материалы, наноэлектронику или физический синтез.

## Политика неизвестных значений

Exact E1/E2 reference sources теперь выбраны и закреплены. По-прежнему не выбраны/не приняты: численные и статистические tolerances, canonical 298 K vs 300 K policy для E2, engine/build versions, измеренный compute budget и права redistribution для E2 data. Эти значения принадлежат следующим bounded Work Orders и не должны подставляться произвольно.
