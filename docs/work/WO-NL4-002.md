# Work Order NL4-002 — E3: измерение вклада ИИ (bounded LLM agent vs random vs grid)

Статус: READY (Author: Director 2026-09-12; owner-решения: target = **90°**, бюджет = **5 прогонов × 50000 шагов на агента**, три агента). Родитель: NL4, issue #8. Ветка оркестрации: `work/nl3-002-e3` нет — `work/nl4-002-e3-r1` от свежего main; arms — отдельные ветки `work/nl4-002-e3-<arm>-r1`.

## Дизайн E3 (пререгистрация; изменения после данных — только E3_PROTO_R2)

- **Задача (одинакова для всех агентов)**: goal-JSON `{target_angle: 90, integrity_gates: frozen E2_PROTO_R1 §4, budget: {max_simulations: 5}, steps: 50000, seeds: allowlist-тройка}`. Пространство кандидатов = allowlist (5 вариантов × 3 seeds = 15 комбинаций; бюджет 5 < 15 — выбор, ЧТО запускать и в каком порядке, есть часть задачи агента).
- **Агенты (равный бюджет, равный allowlist)**: (1) `random` — baseline_random, невариативный порядок; (2) `grid` — baseline_grid, канонический свип, обрезанный бюджетом; (3) `llm` — fresh DSH-сессия как brain через `bounded_agent` (валидация allowlist обязательна; LLM видит goal + allowlist + ОПУБЛИКОВАННЫЕ данные E2 (0b 65.87/11b 73.93/32b 78.09/53b 132.36 в окне 150k) и НЕ видит предложения/результаты других агентов).
- **Реальный ExecutorAdapter**: `scripts/nl4/real_executor.py` — oxDNA через WSL (pinned build, digest-gated входы варианта по source_pins), вход = candidate (variant+seed+50000), гейт-проверки, canonical evidence, wall-cap из бюджета (50k ≈ 0.8 ч; жёсткий кап 1.2 ч/ран). Имплементация — часть NL4-002, тестируется на digest-гейте и одном smoke (50k, seed 201004, вариант 0b) ДО arms.
- **Скоринг**: score = |median_angle − 90| по валидным кадрам (frozen §4 гейты; конвенция [0,180]); агентский итог = его лучший скор; обработка invalid/failed — честная (счётчик бюджета тратится на любой ЗАПУЩЕННЫЙ ран).
- **Winner-критерий**: наименьший |median − 90|; tie → более узкий CI95 медианы. **Повторная проверка победителя** (anti-selection-bias): 2 дополнительных прогона победившей конфигурации со СВЕЖИМИ seeds (204016/205020 — вне allowlist-тройки, разрешено Director'ом пост-кампанию как verification-шаг) — если |median − 90| выходит за пределы, заявленный скор аннулируется.
- **Статистика/отчёт**: per-arm таблицы, all-runs ledger (включая rejected/invalid), финальная сводка «вклад ИИ» = Δ(best baselines − LLM) с честными ограничениями (один target, одна модель дискретного пространства, n=5).
