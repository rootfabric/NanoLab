# Work Order NL3-001 — Register hinge design family

Статус: IN_PROGRESS (EX-NL3-001-R1). Родитель: NL3, issue #7. Репозиторий: rootfabric/NanoLab. Ветка: `work/nl3-001-hinge-family-r1`, base `5fbd6d54341947c890cc5aa5f8031de10a0de1eb` (fresh canonical main: NL2-003 ACCEPTED, стадия NL2 закрыта, frontier NL3, `next_work_order = NL3-001`, merge PR #33).

## Цель

Bounded-пакет: (1) зарегистрировать семейство шарниров Shi–Castro–Arya (`docs/research/HINGE_FAMILY_R1.md`) — проверенная параметризация из первоисточника, структура «семейство → parameter space → первый экземпляр `0b`» (по постановке `E2-SETUP-R1`); (2) замороженный детерминированный экспорт/процедура воспроизведения первого экземпляра `0b` с дайджест-контролем — права источника `UNKNOWN` → режим `REFERENCE_ONLY`, поэтому генерация «с нуля» и вендоринг запрещены, реализуется digest-gated user-side процедура; (3) структурное воспроизведение исходного компонента `0b` — насколько возможно без E2-прогонов: топология/число нуклеотидов/связность/геометрия против характеристик, выводимых из источника. Прогоны динамики НЕ входят (это NL3-002/E2).

Политика неизвестных значений соблюдается жёстко: известные значения переносятся только из опубликованных evidence-поверхностей NL0-001/NL0-002/NL0-003 (с точными ссылками); `UNKNOWN` остаётся `UNKNOWN` (точное определение угла из SI, права redistribution и т.д.); владелец решений не подменяется. Если данных источника недостаточно для полного структурного воспроизведения — gap фиксируется честно (дисциплина S003-класса: «структура/факт без семантики не принимается тихо»), handoff завершается с известными ограничениями, без подгонки.
