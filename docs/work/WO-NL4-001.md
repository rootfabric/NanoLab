# Work Order NL4-001 — Ограниченный исследовательский агент и контроллер

Статус: READY (Author: Director 2026-09-12; frontier NL4, owner-решение «Закрыть NL3 → frontier NL4»). Родитель: NL4, issue #8. Ветка: `work/nl4-001-bounded-agent-r1` от свежего main.

## Цель

Реализовать **контроллер экспериментов** и **ограниченного исследовательского агента** (плюс baselines) как замороженный stdlib-only пакет `scripts/nl4/` + allowlist-конфиг. Это ИНФРАСТРУКТУРА NL4: никакой физики, никаких LLM-ключей, никаких прогонов движка — вся логика тестируется на **mock-исполнителе**. Реальная кампания E3 — отдельный WO (NL4-002).

## Состав (bounded)

1. **`scripts/nl4/allowlist.json`** (замороженный конфиг): допустимые действия агента (`propose_candidate`, `request_run`, `read_analysis`, `stop`), допустимые параметры кандидата (вариант семейства {0b,11b,32b,53b,74b}; опционально steps ∈ {50000,100000,150000}, seed policy), бюджеты (max_simulations, max_wall_minutes), запреты (физика/протоколы/критерии/движок — вне allowlist).
2. **`scripts/nl4/controller.py`**: детерминированный цикл «goal → candidates → executor(адаптер) → analysis → evidence → score → next». Вход: goal-JSON (target_angle, integrity_gate, budget). Executor — ИНТЕРФЕЙС с mock-реализацией (детерминированные псевдоданные из фикстур); реальный движок подключается в NL4-002 тем же интерфейсом. Evidence-записи — те же канонические JSON-конвенции (run ID, digests входов-моков).
3. **`scripts/nl4/agents/baseline_random.py`, `baseline_grid.py`**: baselines БЕЗ ИИ (обязательны до E3): random — детерминированный RNG (seed из goal), grid — полный перебор allowlist-пространства. Одинаковое budget- accounting для всех агентов.
4. **`scripts/nl4/agents/bounded_agent.py`**: bounded-обёртка для LLM-агента (реализуется в E3): принимает предложения извне (JSON-файл/STDIN), ВАЛИДИРУЕТ против allowlist (out-of-allowlist → reject с записью), ведёт бюджет, формирует actions-лог. Сам «мозг» — pluggable; в поставке — scripted mock-агент для тестов.
5. **`scripts/nl4/scoring.py`**: score = |median_angle − target| при прохождении integrity-гейтов frozen `E2_PROTO_R1` (§4 пороги);rejected/invalid — честный учёт.
6. **Тесты** `tests/test_nl4_*.py`: allowlist-негативы (вне-allowlist предложение отклонено и залогировано), бюджет-энфорсмент (исчерпание → stop, не превышение), детерминизм baselines (два прогона → идентичные последовательности), контроллер end-to-end на mock (3-5 кандидатов), scoring-математика, канонический JSON.
