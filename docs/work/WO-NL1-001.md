## Цель

Первый канонический воспроизводимый engine environment для NanoLab (docs/OPERATIONS.md: одна Linux-среда как первый канонический путь):

1. Собрать oxDNA **из pinned upstream commit `00dc7fb9a25bbd8cadbc7503ee2b9f38983c6591`** (тот же субъект, что `E1-PROTO-R1` §2.1), CPU backend.
2. Зафиксировать: ОС/компилятор/cmake-версии, build flags, version string engine, SHA-256 собранных бинарей, все команды установки/сборки.
3. Верифицировать fixture-файлы DSDNA8/MD по SHA-256 против пинов `E1-PROTO-R1` §2.2 (4/4).
4. Технический smoke go/no-go (§4 `E1-PROTO-R1`): engine стартует, `energy.dat` конечен (нет NaN/Inf). Smoke — НЕ наука и НЕ E1-прогон.

6. Опубликовать environment pin как основу dispatch кампании NL1-002/E1 (без изменения самого протокола E1-PROTO-R1).
