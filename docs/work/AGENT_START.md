В конце опубликуй документацию и PR, обнови журнал и подтверждённое состояние. Дай commit, список проверок и одно следующее действие. Не объявляй NL0 закрытым только за выбор эталона.

> Если NL0-001 уже принят, не повторяй его: выбери следующий READY Work ID по зависимостям и имеющемуся разрешению. Если появилось противоречие, установи его по репозиторию и сделай ограниченное исправление или точный blocker, а не бесконечную цепочку review.

## Минимальная локальная проверка Git

```bash
git fetch origin --prune
git status --short
git rev-parse origin/main
git log -5 --oneline origin/main
```

Команды предполагают существующий checkout. При работе через GitHub connector выполнить эквивалентное чтение. Не выводить credentials и не считать отсутствие локального git remote доказательством недоступности подключённого GitHub.
