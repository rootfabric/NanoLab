## Frozen процедура сравнения (механическая)

1. **Integrity gates кампании B-R2** — из terminal report/артефактов фиксируются как PASS/FAIL:
   package verify (`reproduce.py verify`); upstream digest gates (size + blob_sha1, 12/12);
   frame0 oracle self-check ×4 (exact совпадение `design.angle_frame0_deg`);
   per-replica observed exit codes; trajectory completeness (последний кадр == последнему
   запланированному шагу печати; критерий упакованной конвенции).
2. **Per-replica medians**: для каждой MEASURED карты (0b, 11b, 32b, 53b) берутся три
   fresh per-replica `median_deg` ИСКЛЮЧИТЕЛЬНО из анализа упакованной конвенцией
   (`analysis/<run>_analysis.json`, поле `replica_median_deg`, produced by
   `package/convention/analyze_hinge.py run`). Никакие другие числа не используются.
3. **Mechanical per-card classification** (независимый пересчёт по шагу 2):
   `campaign_statistic = median(трёх median)`; сравнение с карточечным
   `reference_replica_envelope_deg` (включительно):
   - `MATCH`: ≥3 валидных реплики, statistic внутри envelope;
   - `MISMATCH`: все три median строго по одну сторону envelope;
   - `INCONCLUSIVE`: иначе (недостаточно валидных реплик либо statistic вне envelope
     без полного directional separation).
   Результат сверяется с `analysis/campaign_<variant>.json` исполнителя; любое
   расхождение пересчёта с исполнителем фиксируется как finding (не «исправляется»).
4. **74b**: `NOT_MEASURED / KNOWN_GAP`, не сравнивается, значения запрещены.
5. **Отклонения**: перечисляются из отчёта исполнителя (§10) как есть; для каждого
   отклонения фиксируется класс (build/tooling/environment/protocol-mechanics) и
   признак: менял ли оно model / scientific observable / reference envelope /
   success criterion. WO-level выбор между `REPRODUCED` и `REPRODUCED_WITH_DEVIATION`
   определяется наличием задокументированных отклонений от published steps/tooling.
6. **WO-level verdict** — по frozen mapping WO-NL5-002-A-R1:
   `REPRODUCED` (0b/32b/53b MATCH, 11b ∈ {MATCH, INCONCLUSIVE}, gates PASS, нет
   отклонений от published steps) / `REPRODUCED_WITH_DEVIATION` (то же числовое
   условие при задокументированных отклонениях без изменения научных порогов) /
   `INCONCLUSIVE` / `FAILED_TECHNICAL` / `MISMATCH`.
